One image summing up the world's news of Tuesday 24 November 2026: seven stories from around the world, drawn as a newspaper front page.

## Run

```sh
python3 render.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`render.py` draws `entry.png` (1024x1024) with Pillow; `main.ts` copies it to `/output/entry.png`.
